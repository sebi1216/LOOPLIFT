# Your input

Put everything about the idea here before `/kickoff`: PowerPoints, documents, PDFs, notes, sketches, screenshots of apps you like.

- `/kickoff` reads these files and turns them into `docs/brief.md`. `/designs` looks here for wishes about the look.
- PDF, images, Markdown and text work best. If Claude can't read a PowerPoint or Word file, save it as PDF here.
- This folder is committed to your private repo. No passwords, keys, client data or other people's personal data.
